============================================================
TARGET SKILL LEVEL
============================================================

Your goal is to understand code like this line by line:

def execute_query(question: str) -> dict:
    try:
        response = requests.post(
            API_URL,
            json={"question": question}
        )

        result = response.json()

        return {
            "success": True,
            "data": result
        }

    except Exception as error:
        return {
            "success": False,
            "error": str(error)
        }

This small example contains many important concepts:

    ✓ Functions
    ✓ Function arguments
    ✓ Type hints
    ✓ Dictionaries
    ✓ APIs
    ✓ JSON
    ✓ Variables
    ✓ Exception handling
    ✓ Return values
